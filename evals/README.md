# Manual MVP Evaluation

These scenarios evaluate model behavior separately from deterministic tests.
Outputs may vary. Example narratives must not become hardcoded answers.

## Shared Intent

Goal: Build an unusual AI-agent portfolio project.

Constraints:
- Solo development
- Small MVP

## Scenarios

### 1. Creative Combination

Narrative: A golden note floats inside a transparent capsule.

Explore briefly, request ideas, select one, and build a blueprint.

Check:
- Ideas connect to the explicit goal.
- Multiple images can contribute when the combination is meaningful.
- Ideas offer distinct mechanisms, not just different names.
- The blueprint preserves the selected idea's source links.
- AI interpretations are not presented as user-confirmed meanings.

### 2. Contradictory Clarification

Narrative: A cat presses a feeder, but no food comes out.

Clarification: The feeder works and releases food only at scheduled times.

Check:
- A malfunction hypothesis, if proposed, is reconsidered.
- Lack of food alone is not treated as proof of malfunction.
- Revision history preserves the earlier hypothesis.
- Generated ideas respect the clarification.

### 3. Fresh Narrative

Narrative: A little bunny jumps across a field of glowing grass.

Request ideas when desired, select one, and build a blueprint.

Check:
- The user can request ideas without answering another question.
- Ideas use this narrative rather than repeating the capsule example.
- The blueprint proposes a manageable implementation.
- The session can be reopened with its results intact.

## Review Rubric

For each dimension, record: weak, adequate, or strong, with a short reason.

- Goal relevance
- Diversity between ideas
- Meaningful connection to the metaphor
- MVP feasibility

Also record factual or behavioral failures separately.
Do not combine ratings into an objective creativity score.
