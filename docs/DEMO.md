# MuseCapsule Demo

## Purpose

Show how a user goal and an imagined scene become traceable product
ideas and an engineering blueprint.

## Before Recording

- Start the backend and frontend using README.md.
- Verify the ChatGPT connection.
- Use a synthetic narrative, not personal information.
- Hide terminal output and account details from the recording.

## Scenario

### 1. Set the Intention

Goal: Build an unusual AI-agent portfolio project.

Constraints [Not required]:
- Solo development
- Small MVP

### 2. Describe the Scene

A cat presses a feeder, but no food comes out.

Show the exploration question, extracted images and proposed hypotheses.

### 3. Add a Clarification

The feeder works and releases food only at scheduled times.

Inspect how the hypotheses respond to the clarification.
A malfunction hypothesis is not required to appear.

### 4. Generate Ideas

Request ideas without answering every exploration question.

Choose one idea whose mechanics meaningfully reflect the narrative.
Show its linked images and hypotheses.

Do not expect a specific title or hardcoded output.

### 5. Build the Blueprint

Explicitly generate the selected idea's blueprint.

Show:
- Metaphor origin and product mechanics
- Core user scenario
- MVP features
- Risks and definition of done

Explain that the interpretation and architecture are proposals.

### 6. Inspect Agent Activity

Show actual node lifecycle events.
Node completion is distinct from successful session persistence.

### 7. Restore the Session

Copy the session ID, reload the page and restore it.
Show that the selection and blueprint remain available without generation.

## Recording Notes

Aim for a concise walkthrough of approximately three minutes.
If waiting periods are shortened during editing, label the cuts.
Do not present edited footage as real-time latency.

## Honest Scope

- Local MVP with ChatGPT plan sharing.
- Prompted JSON with application-side validation.
- Deterministic workflow routing with model-generated content.
- No novelty, market-demand or production-readiness guarantee.
- External search is not part of this demo.
